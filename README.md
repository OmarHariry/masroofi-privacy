# Masroofi privacy policy site

Static GitHub Pages site (`index.html`, no build step, no dependencies) hosting the privacy policy for the Masroofi Android app (`com.masroofi.mobile`).
It contains no app source code.

Proposed URL: https://omarhariry.github.io/masroofi-privacy/

Contact: masroofi.support@gmail.com
Publish: public repo `masroofi-privacy`, Settings -> Pages -> deploy from branch `main`, folder `/ (root)`.
